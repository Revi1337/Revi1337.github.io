## 들어가며
[JMeter](https://www.artillery.io/docs/get-started/get-artillery) 는 JMeter는 Apache Software Foundation에서 개발한 `오픈 소스 성능 테스트 도구`입니다.

- 웹 서버, API, 데이터베이스 등의 성능 및 부하 테스트를 진행할 수 있습니다.
- GUI, CLI 모두 제공되어 로컬 테스트 뿐 아니라 CI 파이프라인에서도 사용 가능합니다.

> 해당 포스팅은 Mac 을 기준으로 작성합니다. 또한 HomeBrew 가 설치되어있는 것을 가정합니다.

## JMeter 설치
Brew 를 통해 JMeter 를 설치합니다.

```bash
brew install jmeter
```
