## Memory
실행 중인 프로그램의 데이터와 명령어는 (메인)메모리(주기억장치: Main Memory)에 저장되며, CPU는 메모리에 저장된 데이터와 명령어를 읽고, 쓰고, 실행합니다. 주기억장치(Main Memory)는 크게 `RAM`, `ROM`, `Cache Memory` 로 나뉩니다. 우리가 통상적으로 사용하는 "메모리" 대부분 RAM 을 의미합니다.
