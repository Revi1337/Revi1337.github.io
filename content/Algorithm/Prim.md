## Prim
`Prim` 알고리즘은 무방향 가중치 그래프에서 `최소 신장 트리(MST)`를 찾기 위한 알고리즘입니다. `임의의 시작 정점에서 출발`하여, MST에 포함되지 않은 정점 중 가장 가까운 정점을 매 단계 선택해 트리를 `연속적`으로 확장하는 방식으로 동작합니다.

- 트리에 포함되지 않은 정점 중 가장 가까운 정점을 매 단계마다 선택하기 때문에, `Greedy` 특성을 가집니다.

> "트리를 연속적으로 확장"의 의미는 트리가 항상 하나의 컴포넌트로 연결되어 있다는 것을 의미합니다.


## Mechanism
Prim 알고리즘의 동작 원리는 다음과 같습니다.

1. 임의의 정점 하나를 선택해 MST(최소 신장 트리)에 포함시킵니다.
2. 현재 MST에 포함된 정점들과 연결된 간선 중, 가장 가중치가 낮은 간선을 선택합니다.
    - 이 간선으로 연결된 정점이 아직 MST에 포함되지 않았다면, 해당 정점을 MST에 추가합니다. (이미 포함된 정점을 다시 연결하면 사이클이 생길 수 있으므로, 항상 MST에 포함되지 않는 정점들만 추가하여 사이클을 방지합니다)
    - 이 과정이 탐욕적 선택(Greedy choice)입니다.
3. 위 과정을 모든 정점이 MST에 포함될 때까지 반복합니다.

## Diff Between Kruskal
크루스칼 알고리즘은 전체 간선을 가중치 오름차순으로 정렬한 뒤, 가장 짧은 간선부터 하나씩 선택해나가는 방식입니다. 이때 간선이 그래프 전역에 흩어져 있을 수 있기 때문에, `MST에 추가되는 간선들이 항상 서로 이어져 있지는 않습니다`. 즉, MST가 중간에 여러 조각으로 나뉘어 있다가 나중에 하나로 합쳐지는 형태가 될 수 있으며, 이 때문에 `MST가 불연속적으로 확장되는 특성`을 가집니다.

반면 프림 알고리즘은 하나의 정점에서 시작해, 현재까지 구성된 MST에 포함된 정점들과 연결된 간선 중 가장 가중치가 낮은 것만을 선택해 연결된 정점을 MST에 추가해 트리를 확장해나갑니다. 항상 MST 내부 정점과 외부 정점 간의 연결만 고려하기 때문에 `MST가 항상 하나의 연결된 구성을 유지한 채 연속적으로 확장되는 특성`을 가집니다.

|           | Prim 알고리즘                                  | Kruskal 알고리즘                                      |
| --------- | ------------------------------------------ | ------------------------------------------------- |
| 기준        | 정점 중심 (vertex-based)                       | 간선 중심 (edge-based)                                |
| 확장 방식     | 현재 MST와 연결된 정점 중에서 가장 작은 간선 선택 -> 연속적으로 확장 | 전체 간선 중에서 가장 작은 것부터 선택 -> MST 전체를 넘나드는 비연속적 확장 가능 |
| 간선 선택 조건  | 현재 MST에 연결된 가장 짧은 간선                       | 전체 간선 중에서 가중치가 가장 낮고, 사이클이 안 생기는 간선               |
| 싸이클 방지 방식 | MST에 이미 포함된 정점인지 여부로 판단 (암묵적)              | 유니온 파인드로 사이클 직접 체크                                |
| 연결 상태     | 항상 현재까지의 트리에서 뻗어나가는 구조 -> 연속적              | 여러 군데에서 간선이 확장될 수 있음 -> 불연속적                      |
| 적합한 그래프   | 밀집 그래프에 유리                                 | 희소 그래프에 유리                                        |


## Implementation
Prim 알고리즘은 Heap 기반, 인접행렬 기반 총 두가지 방법으로 구현할 수 있습니다. 아래 코드는 Heap 기반 기준입니다.

```python
import heapq  
  
def prim(mx_node, edges):  
    graph = [[] for _ in range(mx_node + 1)]  
    for v1, v2, c in edges:  
        graph[v1].append([v2, c])  
        graph[v2].append([v1, c])  
  
    mst, costs = [], 0  
    pq, check = [[0, 3, -1]], [0] * (mx_node + 1)  
    while pq:  
        c, n, pn = heapq.heappop(pq)  # 비용, 현재 노드, 이전 노드
        if check[n]:  
            continue  
        check[n] = 1  
        costs += c  
        if pn != -1:  
            mst.append([pn, n, c])  
        for nn, nc in graph[n]:  
            if not check[nn]:  
                heapq.heappush(pq, [nc, nn, n])  
  
    return mst, costs  
  
  
print(prim(  
    7,  
    [[1, 2, 3],  
    [1, 3, 1],  
    [1, 4, 4],  
    [2, 3, 1],  
    [2, 5, 6],  
    [3, 4, 5],  
    [3, 5, 2],  
    [4, 5, 7]]  
))  
```


결과는 아래와 같이 나오게 됩니다.

```text
# output (MST 를 구성하는 간선들, MST의 비용)  
[[3, 1, 1], [3, 2, 1], [3, 5, 2], [1, 4, 4]], 8
```


## Time Complex
Heap 기반 Prim 알고리즘의 시간복잡도는 `O(E LogV)` 입니다. Prim 내 연산들에 대한 시간복잡도는 아래와 같습니다.

|단계|설명|시간 복잡도|
|---|---|---|
|초기화|시작 정점을 우선순위 큐에 삽입|O(1)|
|간선 선택 및 큐 갱신|우선순위 큐에서 최소 가중치 간선 선택 및 인접 간선 추가|O(E log V)|


인접행렬 기반 Prim 알고리즘의 시간복잡도는 `O(V²)` 입니다. Prim 내 연산들에 대한 시간복잡도는 아래와 같습니다.

| 단계               | 설명                                           | 시간 복잡도 |
| ---------------- | -------------------------------------------- | ------ |
| 초기화              | 시작 정점 선정 및 방문 배열 초기화                         | O(V)   |
| 정점 순회 및 최소 간선 탐색 | 매 단계마다 현재 MST에 연결된 정점과 인접한 정점 중 최소 가중치 간선 탐색 | O(V²)  |
